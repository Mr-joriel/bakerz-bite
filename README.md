Bakerz Bite

Bakery and café single-page website (React + Vite). Aptech eProject. Full details, assumptions and diagrams are in ReadMe.docx and the Project Report.

How to run

Requirements: Node.js 18 or newer, and Chrome, Edge or Firefox.

Open a terminal on this folder.
Run npm install (needs internet once).
Run npm run dev
Open the address shown in the terminal (normally http://localhost:5173).

Click Allow when the browser asks for location so the bottom ticker can show your location.

Notes
No login and no database. Data is in src/data/*.json.
Shop details (Aptech Ajao Center's WhatsApp number, phone, email, address) are in src/config.js.
Production build: npm run build (output in dist/).
